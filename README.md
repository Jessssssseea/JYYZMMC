## 🛠️ 二次开发指南

项目模块化、配置化设计，无需深入代码即可完成内容修改，极低维护成本。

### 1\. 资源替换

- **队干风采照片**：重命名图片为对应姓名，覆盖 `assets/images/leaders/姓名\.jpg`；支持配置 `rand:true` 开启随机双图展示

- **宣传海报/封面**：直接替换 `assets/images/` 目录下对应海报、宣传片封面图

### 2\. 全局样式修改

页面所有配色、圆角、字体均可通过头部 CSS 全局变量统一修改：

```css
:root {
  --bg:#0d1b2a;        /* 全局背景色 */
  --card:#1b263b;      /* 卡片背景色 */
  --accent:#00b4d8;    /* 主题高亮色 */
  --text:#f1faee;      /* 文字颜色 */
  --radius:12px;       /* 卡片圆角 */
  --font:'Segoe UI',sans-serif; /* 全局字体 */
}
```

### 3\. 新增页面栏目

在 `body` 标签内新增模块，同时在导航栏补充对应锚点链接即可：

```html
<section id="新栏目ID">
  <h2>新栏目标题</h2>
  <!-- 自定义内容 -->
</section>
```
